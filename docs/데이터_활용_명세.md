## 2. 전처리 흐름
1. **판별**: 첫 줄 머리글로 데이터 종류를 판별(허브 3종 머리글, 센터 명세서 71종 `csv_columns` 와의 일치도 ≥ 0.6).
2. **읽기**: UTF-8(BOM 포함·미포함)/CP949 자동, 모든 열을 문자로 읽음.
3. **정리**: 가림값(`*`, `**`)·`NA`·빈칸 → 결측, 쉼표 제거 후 숫자 변환, 날짜 `YYYYMMDD` → 날짜, 정류소 이름 앞뒤 공백 제거·연속 공백 정리(743 이름 뒤 공백 다수).
4. **합치기**: 월별 파일 병합·중복 행 제거 → '일 × 단위' 합계(743은 이용자 유형 합, 561은 이용자 유형별 합).
5. **캐시**: 허브 공개 파일의 '일×단위' 합계만 `data/cache/`에 저장(센터 데이터는 캐시하지 않음).
6. **분석**: 날짜×단위 표(빠진 날 NaN) → 대조군 선택(사전기간 하루 평균 20명·자료 충족률 90% 이상, 추세 유사도 RMSE 상위 K) → 비율 이중차분(로그, 요일 보정, 긴 기간은 전년 같은 요일 대비) → 위약검정(시점·지역) → 반대 설명 점검 → 신호등 → 반출 점검.
